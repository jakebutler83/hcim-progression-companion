# v10.31.0 — Multi-Account RuneLite Links

- Stores a separate secure website token for every linked RuneScape character.
- Automatically selects the matching token when the logged-in RuneScape account changes.
- Preserves and migrates the previous single-account token for existing users.
- Renames the public-facing plugin to Progression Path Companion now that regular and solo accounts are supported.
