# Companion v10.12.0 — RuneScape Clan Event Importer

## Added

- New **Sync clan events** setting, enabled by default.
- Reads the in-game **Clan Settings → Events** interface when it is open.
- Captures event title, UTC date/time, duration, world, event type, subtype, and required rank, and creator.
- Uploads only when the interface is first opened or its visible event data changes.
- Reopening the interface forces a fresh import.
- RuneLite panel status shows the imported event count and last successful sync time.

## Limitations

RuneLite does not provide a standalone clan-event collection. The event interface must be opened so the visible widget rows exist. This feature is read-only and does not create or edit RuneScape clan events.
