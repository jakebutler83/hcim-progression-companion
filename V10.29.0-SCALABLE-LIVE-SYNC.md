# v10.29.0 — Scalable Live Sync

- Location and Social Hub presence now share one authenticated live request.
- The normal heartbeat is five minutes, with earlier updates only for meaningful state changes.
- Every client receives randomized scheduling jitter so a large population cannot create a synchronized request spike.
- Failed requests back off from 30 seconds to a maximum of 15 minutes and automatically recover after a successful request.
- If the transition endpoint is not deployed yet, the plugin safely falls back to the existing location and presence endpoints.
- Clan rosters are uploaded only when their content changes.
- New installations require explicit opt-in for Social Hub presence, clan roster sync, clan event sync, exact location, Group Storage, and weekly loot tracking.
- All third-party network features now show RuneLite's required privacy warning.

Existing saved plugin choices remain unchanged.
