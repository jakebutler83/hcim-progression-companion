# v10.32.0 — Solo Personal Bank

- Added the opt-in **Sync Personal Bank (Solo)** setting.
- Captures `InventoryID.BANK` only while `InterfaceID.BANKMAIN` is open.
- Debounces bank-container changes before uploading the latest complete snapshot.
- Uses a dedicated character-scoped `companion-personal-bank-sync` endpoint.
- Shows Personal Bank waiting, syncing, success, error, and disabled states in the companion panel.

Personal Bank sync is read-only. It never deposits, withdraws, clicks, or changes an in-game item.
