# v10.20.0 — Group Storage Sync

This update adds an opt-in Group Storage snapshot for the Progression Path Group Bank.

## What changed

- Captures item IDs, names, and quantities when the in-game shared storage is opened or changed.
- Waits briefly for storage updates to settle before uploading one snapshot.
- Uses the existing private companion link token and an asynchronous RuneLite HTTP client.
- Adds Group Storage status to the RuneLite side panel.
- Leaves the feature disabled by default with RuneLite's required third-party server warning.

## Important behavior

RuneLite cannot inspect shared storage while nobody has it open. The website therefore shows the most recent snapshot uploaded by a linked group member, including who synced it and when.

The feature is read-only and performs no gameplay automation.
