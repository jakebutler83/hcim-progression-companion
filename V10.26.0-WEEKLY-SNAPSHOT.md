# Companion support for Progression Path v10.26.0

- Account Sync continues to send current skills, XP, quests, clue totals, boss KC, and Collection Log totals so the website can calculate daily and weekly changes.
- The new disabled-by-default **Track NPC loot value** option listens to RuneLite's NPC loot event and keeps a RuneScape-profile-scoped cumulative GE-value total.
- Loot never generates a network request during gameplay. Totals are included only when the player presses **Sync Account**.
- The companion does not automate gameplay or interact with inventory, NPCs, movement, or the game client.
